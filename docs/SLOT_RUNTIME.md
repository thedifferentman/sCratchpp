# 共享槽位运行时

后端将现有 LLVM 运算降为按需生成的 Scratch warp 过程。运行时过程接收 SSA 槽位地址并写回目标槽，调用点不再逐字节读取、打包参数、保存返回寄存器。它没有新增 `execute(opcode, ...)` 解释器；操作、位宽、布局及调用签名在编译期决定。

## 地址和生命周期约定

- `D/A/B` 是 `__scl_memory` 中可信的内部槽位下标；`P` 是保存完整 LLVM 指针位模式的槽位。两者不可混用。
- 指针只有在解引用时才完整解码和检查。高于第 24 位的任何非零字节都不能截掉；非空访问还须位于数据区和配置容量之间。GEP 自身不要求结果可解引用，允许 one-past 等地址计算。
- 内部复制具有 memmove 语义，包括部分重叠；数值过程在改写 D 前保存需要的源值。程序 memcpy 对定义良好的非重叠输入保持原语义，底层实现也能处理重叠。
- load/store 每个实际访问的客体字节只读取或写入一次；非整字节 store 在写入前规范化源的最高字节。SSA 私有存储的读写不代替客体 volatile 访问。
- 数值、内存和普通指令辅助过程不会调用 LLVM 用户代码；其私有 Scratch 临时变量只在当前调用期间有效。调用适配器可能递归进入用户函数，但没有临时寄存器需要在用户调用返回后继续读取。真正跨调用存活的值保存在原有 LLVM 栈帧中。
- `phi` 的循环临时值放在当前函数的 outgoing 区，作用域仅限一条 CFG 边；该阶段没有用户调用。只有发生复制依赖环才保存临时值。
- 原子操作继续限于单执行上下文。ASM 包装可能包含等待/询问；当前只有一个 LLVM 执行上下文，不能从并发事件重入这些临时状态。接入异步执行或线程时必须重新审查。

## 实现分层

| 文件/层 | 职责 |
|---|---|
| `src/slot_memory.cpp` | 固定 1/2/4/8 字节及通用复制、填充，完整指针解码、范围检查，合并 load/store，程序内存 intrinsic，地址编码、帧进入/离开、栈恢复和统一 trap |
| `src/slot_numeric.cpp` | 整数运算、比较、转换和 intrinsic 的槽位接口；沿用既有精确字节算法与查表 |
| `src/constants.cpp` | 任意宽度常量、聚合布局、向量打包、转换、比较、符号重定位后的 GEP 等编译期求值 |
| `src/backend.cpp` | SSA 槽位与视图、常量池、复制计划、专用指令过程缓存、控制结构与调用/尾调用调度 |
| `src/varargs.inc` | 当前 SysV 标量 ABI 的打包、读取、复制和结束处理，复用槽位原语 |
| 现有浮点降级与 SoftFloat | 浮点操作仍降为已有整数 ABI 函数；参数、返回、内部整数和内存运算共同使用新槽位机制 |

普通算术不依赖小数近似。`udiv/urem/sdiv/srem` 每个位宽共用一份无符号除余核心，有符号包装负责符号处理。常量移位按字节位置及剩余位数生成专用过程，动态移位保留通用算法；2 次幂常量乘法转成常量左移。非法移位和除法边界继续采用现有确定性 undef/poison 策略，并不新增 LLVM 的定义行为。

向量算术、比较、转换、归约、动态元素操作、非整字节打包、掩码访存及原子操作，通过按类型和指令形状缓存的槽位入口复用已有实现。scalar 核心仍被共享，LLVM 指令不会在调用点重复展开这些算法。固定 shuffle 的掩码和聚合偏移用于生成复制/取值计划，不在运行时解释掩码。

## 编译期处理

同位宽 bitcast、ptrtoint/inttoptr、合适的 freeze、字节对齐的固定聚合字段提取使用槽位视图。零 GEP 和同一来源的平凡 phi 可合并槽位；相同源目标的内部复制消除。加零、乘一、零移位等先简化；纯常量指令由宿主精确字节求值器处理。

GEP 合并常量偏移，步长 1 不乘法，2 次幂步长改移位。它保留指针和索引位宽的区别，不将合法的地址计算与访存检查混在一起。

常量槽按最终字节模式去重，类型由各调用接口保留。常量池在静态区分配完、函数生成完成后确定最终堆边界，不与帧或动态对象重叠。启动时先将虚拟内存清零；少量非零字节直接写入，大量初始数据存入数值表并由一个共享过程写入。表项都是数，单表长度不超过原版 Scratch 容量限制；它们是常量表，虚拟地址仍只指向 `__scl_memory`。

构造/析构的顺序和直接入口在编译期解析，包括别名。一般间接调用继续使用最终函数 ID 的二分分派。`musttail` 仍通过 trampoline 转移，不增加 LLVM 调用帧。CFG 分派每轮只读取一次 PC；大型过程的拆分与槽位化共同保留。

## 验证

直接运行时测试为 `slot-runtime`、`slot-runtime-vm`；覆盖源目标正反向重叠、宽整数、非整字节宽度、常量移位、零长度内存操作、编码指针高位、越界及错误状态。常量求值器另有 `constants` 测试。

IR 集成用例包括 phi 环、递归、直接/间接调用同名缓存、静态数值表、非整字节向量、原子旧值与成功标志、关闭掩码 lane 的非法地址，以及既有浮点、变参、musttail 和构造析构回归。直接调用 `@indirect` 与真正间接调用使用不同结构化缓存键，避免字符串名称碰撞。

此变更没有实现文件系统、Console、事件或线程，也没有扩展已有 LLVM 功能边界。实际测试结果和模板体积对比见 [验证记录](SLOT_RUNTIME_RESULTS.md)。
